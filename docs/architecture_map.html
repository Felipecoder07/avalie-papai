Categoria Padrão Adoptado Rationale / Motivo de Engenharia
Isolamento Multi-Tenant Logicamente isolado via tenant_id em todas as tabelas operacionais. Garante alta performance no SQLite mantendo rigidez absoluta nas consultas parametrizadas.
Separação de Gateway Access Token Master (Mensalidades SaaS) vs Access Token Tenant OAuth (Reservas Atletas). Impede cruzamento de caixas entre o dono da plataforma SaaS e os donos das arenas.
Live Polling Fallback Polling a cada 4s no modal Pix com consulta direta à API do Mercado Pago. Resolve a limitação de webhooks no ambiente local (localhost) garantindo teste e uso perfeitos.
Convenção de Arquivos Backend MVC em camelCase.js | Frontend React TSX em PascalCase.tsx. Facilita a identificação imediata dos componentes no monorepo desacoplado.
Gravidade Item Encontrado Descrição & Recomendação
Média Registro Duplicado de Rotas no Backend Algumas rotas possuem declaração no server.js e no app.js. Recomenda-se mover o registro de rotas 100% para dentro de app.js.
Baixa Diretório /frontend Antigo Obsoleto A pasta /frontend na raiz guarda os protótipos HTML estáticos anteriores à migração do React. Pode ser deletada ou arquivada.
